# 月度 / 季度监管分析报告

> **历史版（Legacy）**：本文描述旧 V1 报告聚合接口，不属于当前政府五量 V2 的
> 默认 API 或领导界面。当前报告、风险和回复流程见
> [V2 部署手册](../../docs/V2部署与运行.md#8-v2-交换接口)。

## 定位

该功能对应建设方案二期的“月度、季度监管分析报告”基础闭环。它是平台现有
领导统计、安全预警和生产交叉核验的确定性只读汇总，不调用大模型，不自动
外发，不签批、不立案，也不改变任何案件或预警状态。

输出只形成辅助监管技术线索，不是安全、违法、责任或处罚认定。无预警、
生产核验状态为 `ready` 或线索等级为 0，均不能解释成矿井安全或合规。

## 使用方式

登录领导监管工作台，在“辖区总览”底部选择：

1. 月度报告或季度报告；
2. 年份；
3. 月份或季度；
4. 北京时间 `Asia/Shanghai`。

点击“生成只读报告”后，先检查报告顶部的数据完整性状态，再查看逐矿明细。
确认页面内容符合本次人工汇报需要后，可以点击“打印 / 另存为 PDF”。浏览器
打印只是本地输出，不代表审批、签章或送达。

## API

```text
GET /v1/reports/regulatory?kind=monthly&period=2026-07&timezone=Asia%2FShanghai
GET /v1/reports/regulatory?kind=quarterly&period=2026-Q2&timezone=Asia%2FShanghai
```

请求规则：

- 必须登录，并具备 `data.read` 权限；
- 数据范围严格取当前账号的矿井授权范围；
- `kind`、`period`、`timezone` 必须各出现且只出现一次；
- 月度键只能是 `2020-01` 至 `2100-12`；
- 季度键只能是 `2020-Q1` 至 `2100-Q4`；
- 时区当前只接受 `Asia/Shanghai`；
- 拒绝未来周期、任意日期范围、额外参数和重复参数；
- 只提供 `GET`；响应为 `Cache-Control: no-store`。

当前月份或季度可以生成，但 `period.complete=false`，`data_end_at` 明确记录
实际统计截止时间，报告质量至少为 `incomplete`。

## 汇总口径

报告复用三类平台现有结果：

- `calculate_leadership_analytics`：报送覆盖、逐矿关注排序、重复异常、案件新增、
  关闭和当前积压；
- 安全驾驶舱及预警台账：报告期内触达的正式/影子预警，以及生成时刻的当前
  安全驾驶舱快照；
- 生产交叉核验：每矿取 `window_end` 落在报告期内的最新核验结果。

报告期安全预警的纳入规则是：当前预警记录的首次发现时间不晚于
`data_end_at`，且最后出现时间不早于 `start_at`。由于当前台账不是历史快照，
报告会明确提示“生成时刻汇总”，不能把后来关闭的状态伪装成报告期末状态。

生成时安全驾驶舱的开放预警数单独标为“当前快照”，不与报告期预警数混用。

## 缺失和阻断语义

逐矿报送状态：

- `received`：有应报记录且实收数量达到应报数量；只表示记录接收，不表示真实；
- `missing_report`：实收少于应报；
- `data_incomplete`：已接收，但数据或计算条件不足；
- `no_report_records`：没有可统计应报记录，不能判断正常。

生产核验状态：

- `ready`：算法已完成；不是合规认定；
- `insufficient_history`：合法历史样本不足，不能判断正常；
- `blocked`：被数据质量或必要条件阻断；
- `not_run`：本期没有核验结果；
- `unknown`：无法识别的状态，按不完整处理。

报告数据质量状态：

- `blocked`：存在完整性失败、读取上限、缺报、无应报记录或核验阻断；
- `incomplete`：存在当前未完结周期、非治理批次、历史不足、未运行核验或无效
  时间等不完整项；
- `complete_for_review`：达到当前技术复核统计口径，仍必须人工复核。

源读取达到 1000 条安全上限时不静默截断，而把报告标为 `blocked`。未通过
批次完整性校验的数据不参与统计，同时显式记录阻断。

## 安全和边界

- API 在取数前应用账号矿井范围，汇总中不包含未授权矿井；
- 服务端只返回 JSON，不接受或生成任意 HTML；
- 页面通过 `textContent` 和 DOM 节点展示矿名、标题和说明，不使用 HTML 注入；
- 查询参数不是文件路径、SQL 或模板片段，固定格式校验后才参与计算；
- 报告引用由报告期、矿井范围和所用记录标识确定性摘要而来，不是电子签名；
- 本版不保存报告制品、不提供自动发送和审批工作流。

## 当前限制和后续建设

本版是可直接使用的报告预览/打印闭环，但正式上线仍应补充：

1. 经主管单位批准的应报日历、停产检修豁免和节假日口径；
2. 报告历史快照或不可变制品库、电子签章和审批流（如纳入正式范围）；
3. 真实消息/公文系统的人工批准后发送和送达回执；
4. 超过单次读取上限后的游标式全量取数；
5. 现场数据源、规则、矿井档案和合法历史样本验收。

以上扩展不得把技术报告自动提升为监管认定。
