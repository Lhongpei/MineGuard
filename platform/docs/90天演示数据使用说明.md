# 90 天演示数据使用说明

> **历史版（Legacy）**：本文命令和页面针对旧 V1 多算法/edge 演示，不属于当前
> 默认产品。当前只有一矿一 `agent/` 与政府 `platform/`，请改用
> [十量 V3 部署与运行](../../docs/十量V3部署与运行.md)。

这套数据只供本机体验领导监管工作台。它包含 6 座虚构矿井、90 个自然日的
报送、算法特征、核查事项、安全线索和吨煤核验结果。数据会进入真实后端读模型，
时序曲线由现有算法重新计算，不是前端写死的图片。

## 一次生成并启动

在项目目录执行：

```bash
cd /home/sevan/coral/platform
python -m pip install -c constraints.txt -e .

mineguard seed-demo \
  --state-directory .mineguard-demo \
  --days 90 \
  --reset

MINEGUARD_ADMIN_PASSWORD='123123123' \
  mineguard serve \
  --host 127.0.0.1 \
  --port 8080 \
  --state-directory .mineguard-demo
```

浏览器打开 <http://127.0.0.1:8080/>，使用：

```text
账号：admin
密码：123123123
```

终端停在 `MineGuard listening ...` 是服务正在等待浏览器请求，不是卡死。保持
该终端运行；需要停止时按 `Ctrl+C`。

上述弱口令只适用于当前回环地址上的隔离演示。不要把这条命令原样监听到
`0.0.0.0`，也不要将 `.mineguard-demo` 当作正式状态目录。

## 建议体验顺序

1. 登录后默认进入“领导简洁模式”。确认顶部出现橙色“演示数据”横幅，在“今日
   态势”查看报送覆盖、高优先线索、超期事项、待审批数量和三条今日重点。
2. 进入“待我决策”，查看待审批、超期、责任人未明确、P1/P2 事项和红橙安全线索；
   点击“进入办理”时，页面会切换到监管专业模式并打开对应专业工作区。
3. 进入“监管报告”，体验月度或季度只读报告。
4. 切换“监管专业模式”，在“辖区总览”查看近 30 日趋势、重复异常、风险排序、
   案件积压和办理时效。
5. 在“时序异常与数据质量”中切换矿井与指标。曲线展示观测值、历史基线、参考
   范围和异常点；优先选择异常序列时可看到缓慢漂移、变化点或重复异常。
6. 进入“核查台账”，体验待分派、复核中、待补数、待审批、已闭环和重开记录。
7. 进入“安全态势”，查看虚构矿井点位、人员/甲烷/通风最新值、来源断流线索和
   吨煤核验热力排序。演示预警保持影子模式，不发送通知。

六座矿井分别用于展示稳定基线、缓慢漂移、变化点、重复异常、间歇缺报，以及
来源健康和安全线索。页面结论均是技术核查线索，不是违法或责任认定。

## 查看状态、重建和清空

先停止正在运行的演示服务，再执行：

```bash
cd /home/sevan/coral/platform

# 查看数量和完整性
mineguard demo-status --state-directory .mineguard-demo

# 用同一模板重新生成
mineguard seed-demo \
  --state-directory .mineguard-demo \
  --days 90 \
  --reset

# 只清空演示业务数据
mineguard clear-demo --state-directory .mineguard-demo
```

`seed-demo` 和 `clear-demo` 都要求目标目录带有生成器创建的所有权标记；非空的
普通目录和正式状态目录会被拒绝。重建只处理 `pilot-demo90-*`、
`DEMO-M*` 等演示命名空间。

如需让同一份演示在不同日期重复得到完全一致的窗口，可固定结束日：

```bash
mineguard seed-demo \
  --state-directory .mineguard-demo \
  --days 90 \
  --anchor-date 2026-07-28 \
  --reset
```

## 三套系统分别做什么

- 企业端智能体：整理本企业材料、提示缺项、保留来源摘要、要求人工确认并提交；
  它不做辖区排名，也不能查看其他企业或替监管人员定案。
- 矿端 `edge-agent`：只读自动采集设备和业务系统数据，负责本地留存与断网续传。
- 监管平台：汇总多企业报送和矿端采集，独立执行物理、历史、时序、来源健康
  分析，再由领导和监管人员分派、复核、审批及留痕。

正式部署时，演示生成器不能代替自动数据接入。现场连续数据应由
`edge-agent` 或经批准的业务系统适配器采集；企业报送仍通过双方约定的独立
HTTP/JSON/HMAC 接口进入监管平台。
