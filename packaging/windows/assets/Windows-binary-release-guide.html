Windows 安装后快速使用指南

政府监管平台和企业侧智能体是两个独立软件。请只按本机安装的产品执行对应步骤。

先确认交付可信度

文件名含 UNSIGNED-TEST-ONLY 的安装包仅供隔离验收，不得作为正式可信发布。正式候选包必须同时核验单位批准的 Authenticode 签名、时间戳以及随交付清单提供的 SHA-256。

Server 2012 R2 legacy 测试包

文件名含 LEGACY-SERVER-2012R2 的安装包只用于真实目标机兼容性验收，尚未获得生产批准。目标机必须是完全修补的 x64 Server 2012 R2，并先安装 Windows Management Framework 5.1；系统自带的 Windows PowerShell 4.0 不满足要求。目标 CPU/虚拟 CPU 还需暴露 x86-64-v2 指令集，并具备 Universal C Runtime 和 Microsoft Visual C++ x64 运行库。

安装后必须依次验证 self-check/HiGHS、前台健康、Windows 服务、数据库备份与恢复、升级和卸载。领导端应从仍处于安全支持期的办公终端浏览器经 HTTPS 访问，不要依赖 Server 2012 R2 本机的旧浏览器。

政府侧 Platform：先从控制中心启动

安装完成后，无需输入 PowerShell 命令。从 Windows 桌面或开始菜单打开 “MineGuard Platform 控制中心”；系统询问管理员权限时选择“是”。

只想马上看效果

  1. 选择“本机展示（推荐先看）”。
  2. 勾选红色确认项，再点“一键准备并启动展示”。
  3. 健康检查通过后，控制中心会优先用 Edge 或 Chrome 打开领导端。

演示账号是 admin，密码是 123123123。它只监听本机、只供展示， 不得用于正式运行、企业报送或监管认定。Internet Explorer 不受支持；未安装 Edge/Chrome 时，控制中心会显示地址和提示，而不会用 IE 打开空白页面。

配置正式内网环境

选择“正式内网配置”，依次选择经批准的 clients.json、专用状态数据目录和 本机端口，填写管理员账号及两遍密码；单位 HTTPS 反向代理已就绪时，再填写领导端 HTTPS 地址；地址必须以 https:// 开头，且不能包含账号口令、查询参数或片段。 该地址只用于本次安全打开浏览器，不会替管理员配置反向代理，也不会持久保存。 正式密码不能使用 123123123。控制中心不会把密码写进命令行或运行日志； 非敏感运行记录保存在受保护的 logs\control-center-*.log。

控制中心启动的是前台验收进程：窗口保持打开才会继续运行，关闭窗口会先询问并停止本次 启动。正式长期运行仍应由管理员使用单位批准并核验过的 WinSW 安装 Windows 服务。

高级管理员：仍可使用原 PowerShell 配置入口 
Set-Location 'C:\ProgramData\MineGuard\Platform\service'
& '.\Set-MineGuardPlatformConfiguration.ps1' `
  -InstallRoot 'C:\ProgramData\MineGuard\Platform' `
  -ClientsFile 'D:\approved-media\clients.json'

具体命令见开始菜单的“MineGuard Platform 使用与部署说明”。先运行 Start-MineGuardPlatform.ps1 前台验收，再用 Test-MineGuardPlatform.ps1 检查健康状态；正式对外访问应由批准的 HTTPS 反向代理提供。

企业侧 Agent（一矿一智能体）

  1. 从开始菜单打开“Create an enterprise mine instance”。
  2. 为本矿填写独立实例名、煤矿编号、企业编号、系统身份和本机端口。
  3. 在生成的 ProgramData 实例目录内配置账号摘要、政府接口、两把不同的交换密钥以及可选模型 API；不要把明文密码或密钥写入命令行。
  4. 用 Start-EnterpriseAgent.ps1 前台启动，用 Test-EnterpriseAgentHealth.ps1 验收，再按 deploy\windows\README.md 安装本矿服务。
Set-Location 'C:\Program Files\MineGuard\EnterpriseAgent\deploy\windows'
.\New-EnterpriseAgentInstance.ps1 `
  -InstanceName qinyuan-001 -MineId MINE-QY-001 `
  -MineName '本矿名称' -OperatorId OP-QY-001 `
  -OperatorName '本企业名称' -SystemId agent-qy-001 -Port 8090

升级、卸载与数据

  • 升级前先停止对应服务，制作完整备份并验证恢复流程。
  • 允许同版本修复和向更高版本升级；默认拒绝覆盖安装更低版本。旧 Python/venv Agent 必须先逐矿移除旧服务注册，安装二进制版后再逐矿注册服务，实例数据不会因此删除。
  • 状态必须使用本机固定 NTFS 上用途单一的专用目录；不得指向程序/runtime/service/源码目录、整个安装根、整个 ProgramData、磁盘根、网络/同步目录或 junction/reparse point。
  • 卸载前先运行产品自带的服务移除脚本。
  • 卸载器只移除不可变运行时和部署脚本，不删除 ProgramData 中的政府业务状态或企业实例。卸载后仍须按单位数据保留制度处置这些目录。
  • 目标机运行离线安装包不需要 Python、Node.js、编译器、GPU 或互联网；联网业务本身仍需要批准的网络、DNS、证书和准确系统时间。

前端 HTML/JavaScript/CSS 与运维 PowerShell 为可见文本；后端由 Nuitka 编译，但任何 EXE 都不能视作绝对不可逆向。完整说明见交付文档《Windows二进制发行与安装》。
