怎么判断系统是否正常？

  1. 顶部显示“运行正常”，说明本地服务和数据库可用。
  2. “待上报”短时增加是正常现象；网络恢复后会自动重试。
  3. 待上报长期不下降时，联系运维检查监管接收地址、网络和 HMAC 密钥。
  4. 采集来源显示“缺数”或“失败”时，只影响该来源；其他来源和上报仍会继续。
  5. 红色安全预警必须立即按矿井既有制度人工核实；本系统不自动控制设备。

数据从哪里来？

支持 JSONL 文件、投递目录、HTTP 只读轮询和受控 HTTP 推送。人工补录必须填写人员、原因和凭证，页面会明确标记“人工”。

安全边界

来源页的“启用/暂停”只控制本节点是否读取该连接器，不会启停风机、传感器或任何生产设备。本节点没有修改传感器、下发生产参数、删除源数据等接口。
